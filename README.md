# Mr. Dane's Jobs

HTML5 educational game (Mr. Dane's Job Town - P6 Career Game).

## How to make it live on GitHub Pages

1. Go to the repository Settings → Pages
2. Under "Build and deployment" → Source: select "Deploy from a branch"
3. Branch: main, folder: / (root)
4. Click Save

The page will be available at: https://masterdaneding.github.io/Mr-Danes-Jobs/

The game expects the image assets in folders such as Backgrounds/, Miss-Pink-9-roles/, Signs/, etc. relative to index.html. Please upload those from your "P6 Game" folder if they are not yet present.
