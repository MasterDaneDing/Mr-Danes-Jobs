# Mr. Dane's Jobs

HTML5 educational game (Mr. Dane's Job Town - P6 Career Game).

**Live:** https://masterdaneding.github.io/Mr-Danes-Jobs/

Open `index.html` at the repo root (GitHub Pages deploys from `main` / root). Assets live in `Backgrounds/`, `Signs/`, and the character `*-9-roles` folders alongside the page. A `.nojekyll` file is present so Pages serves paths as-is.
